
# CampusPulse – Smart Campus Issue Management System

CampusPulse is a smart campus issue management platform designed to help students report campus problems and help administrators track, prioritize, and resolve them efficiently.

## Features

- Complaint submission and management
- Smart duplicate complaint detection
- Search and filter complaints
- Issue priority and status tracking
- Analytics dashboard with visual charts
- Campus hotspot identification
- Recurring issue detection
- Smart recommendations
- Automatic escalation monitoring for overdue complaints
- Local storage for complaint persistence

## Tech Stack

- React.js
- JavaScript
- CSS
- Recharts
- Lucide React
- Vite
- Local Storage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/23A31A0527/CampusPulse.git
```

Navigate to the application folder:

```bash
cd campuspulse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Project Purpose

CampusPulse aims to improve campus maintenance and issue resolution through centralized complaint tracking, data-driven insights, and automatic escalation.
